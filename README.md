# Udemy Clone

A responsive Udemy-inspired course marketplace homepage built with HTML and CSS. This project recreates the visual layout of an online learning platform for frontend practice.

## Features

- Sticky navigation bar with branding, search field, course links, and icons
- Course category navigation
- Promotional flash-sale banner
- Recommended and popular course sections
- Course cards with images, ratings, and pricing
- Recommended topics section
- Hover popup for the My Learning area
- Footer with common platform links

## Technologies

- HTML5
- CSS3
- Google Fonts (Gabarito)
- Font Awesome icons

## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/sakthi4empower-vijay/Udemy-Clone.git
   ```

2. Open the project folder.
3. Open `index.html` in a web browser.

You can also use the Live Server extension in VS Code for automatic browser refresh while developing.
